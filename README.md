A GTA 6 meme drawn programmatically with Python and Pillow (meme.py): after thirteen years of waiting, a cobwebbed skeleton still sits on a Leonida beach couch with a controller in its hands, while the make.fun ghost next door already got paid in week one. The ghost mascot and a neon make.fun sign are worked into the sunset scene. main.ts copies POST.json (the X post's address) to the output directory; that is the whole entry program.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 meme.py
```
